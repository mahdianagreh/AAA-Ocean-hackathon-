Root cause (from `docker compose logs api`, full traceback below): main.py's
currents_agreement() checks `hycom_path.exists()` and returns a clean 503 if it's
missing, but has NO equivalent existence check for `copernicus_path` before calling
oc.compare_hycom_vs_copernicus(lon, lat, time, hycom_path=hycom_path,
copernicus_path=copernicus_path). Only the HYCOM historical cache
(data/raw/currents/hycom_aoi_AQ-2016-10-28.nc) actually exists on disk — Copernicus
Marine credentials were never configured (documented elsewhere as "not yet provided"),
so copernicus_marine_aoi_AQ-2016-10-28.nc was never cached. The missing file reaches
xarray.open_dataset() unchecked and raises FileNotFoundError, which FastAPI surfaces
as a bare 500, not the graceful 503 the sibling hycom check produces.
